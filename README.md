# Refund API

API REST desenvolvida durante os estudos do curso Full-Stack da [Rocketseat](https://www.rocketseat.com.br/).

O projeto tem como objetivo desenvolver uma API para gerenciamento de solicitações de reembolso, aplicando conceitos de desenvolvimento backend com Node.js e TypeScript.

## 🚀 Tecnologias utilizadas

- **Node.js** – Ambiente de execução JavaScript.
- **TypeScript** – Tipagem estática para JavaScript.
- **Express** – Framework para criação de APIs REST.
- **Prisma ORM** – Ferramenta para comunicação com banco de dados.
- **JWT (JSON Web Token)** – Autenticação baseada em tokens.
- **Bcrypt** – Criptografia de senhas.
- **Zod** – Validação de dados.
- **Multer** – Gerenciamento de upload de arquivos.
- **CORS** – Controle de acesso entre diferentes origens.

## ⚙️ Funcionalidades e conceitos estudados

- Desenvolvimento de API REST.
- Estruturação de aplicações backend.
- Gerenciamento de solicitações de reembolso.
- Autenticação com JWT.
- Criptografia de senhas com Bcrypt.
- Validação de dados utilizando Zod.
- Integração com banco de dados através do Prisma.
- Upload de arquivos com Multer.
- Organização de rotas e tratamento de erros.

## 📦 Como executar o projeto

### Pré-requisitos

- Node.js instalado.
- npm instalado.
- Banco de dados configurado para o Prisma.

### 1. Clone o repositório

```bash
git clone https://github.com/MiguelS-Dev/refund_api.git
```

### 2. Acesse a pasta do projeto

```bash
cd refund_api
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Configure as variáveis de ambiente

Crie um arquivo `.env` na raiz do projeto e configure as informações necessárias para a conexão com o banco de dados e autenticação.

### 5. Execute as migrations do Prisma

```bash
npx prisma migrate dev
```

### 6. Inicie o servidor

```bash
npm run dev
```
